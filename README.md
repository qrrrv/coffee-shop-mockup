# Кофейня — демонстрационный адаптивный макет

Одностраничный сайт-макет для небольшой независимой кофейни. Это **не официальный сайт** и не публикация заведения: страница нужна для обсуждения визуальной концепции с владельцем.

## Посмотреть

Страница работает без сборки и внешних библиотек.

1. Распакуйте архив.
2. Перейдите в папку `coffee-shop-mockup`.
3. Запустите локальный сервер:

    python3 -m http.server 4173

4. Откройте в браузере: **http://127.0.0.1:4173/**

Можно открыть и напрямую файл `index.html`, но локальный сервер надёжнее для шрифтов и предпросмотра.

## Что уже есть

- адаптивная вёрстка для компьютера, планшета и телефона;
- верхняя панель с липкой навигацией и мобильным меню;
- первый экран с кнопками «Посмотреть меню» и «Как добраться»;
- краткое описание кофейни;
- компактное меню с тремя категориями, переключателями и клавиатурной навигацией;
- атмосфера и три стоковые фотографии, явно помеченные как заглушки;
- контакты, часы, адрес и кнопки связи;
- подвал с навигацией, слотами для соцсетей и дисклеймером;
- диалог с пояснением, если данных для действия ещё нет;
- поддержка prefers-reduced-motion, видимые состояния фокуса и семантическая разметка.

## Что нужно заменить перед реальным запуском

Все явно неизвестные данные намеренно оставлены с заглушками [уточнить у владельца] и подсвечены в интерфейсе.

- index.html — название кофейни, город, точный адрес, часы работы, телефон/мессенджер, соцсети;
- assets/app.js — объект DIRECT_LINKS в начале файла:
  - contact → "tel:+7..." или ссылка на мессенджер;
  - directions → ссылка на карту по точному адресу (например, Яндекс.Карты);
  - social-telegram, social-vk → ссылки на профили.
- Все цены и позиции меню — нейтральный **пример для макета**, не данные реальной кофейни. Их нужно заменить или удалить.
- Фотографии — стоковые заглушки. Перед запуском заменить на фото заведения, права на которые подтверждены.

Когда ссылки в DIRECT_LINKS заполнены, кнопки автоматически начинают открывать телефон, мессенджер, карту и соцсети. Пока поля пустые, кнопки не «врут» и не ведут на выдуманные контакты: вместо этого открывается понятное пояснение.

## Технические заметки

- Шрифты: Literata, Manrope, Caveat (OFL), лежат локально в assets/fonts/.
- Никаких внешних CDN, аналитики, форм заказа, оплаты или регистрации.
- Добавлен meta robots="noindex, nofollow", чтобы случайная публикация макета не индексировалась как официальный сайт.
- Страница статическая: index.html, assets/styles.css, assets/app.js.
